## Import into Cardmarket
1. On Cardmarket, create a Wants list (Wants → Create list → Magic) named e.g. "Counter Blitz upgrades".
2. Paste the contents of [`counter-blitz.cardmarket.txt`](counter-blitz.cardmarket.txt) (below) into **Add Deck List** and press **Add**.
3. Open the list and use **Shopping Wizard** to find the cheapest combination of sellers.

The same text also works for TCGplayer Mass Entry.
